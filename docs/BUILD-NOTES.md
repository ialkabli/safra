# حالة البناء والتحقق

نجح تجميع جميع ملفات Java وموارد أندرويد، وتحويل الشيفرة إلى DEX وتوقيع APK والتحقق من توقيع v2/v3 باستخدام أدوات Android SDK المحلية. نجحت 14 حالة تحقق لقواعد الأعمال المستقلة عن أندرويد لكل تطبيق.

تعذر تشغيل Gradle هنا بسبب فحص canWrite في بيئة التنفيذ المقيدة؛ لذلك بُنيت ملفات التثبيت مباشرة بأدوات SDK. ملفات Gradle محفوظة لفتح المشروع وبنائه في Android Studio، لكن لم يُثبت نجاح بناء Gradle في هذه الجلسة. مسار SDK الخاص بالجهاز مستبعد من المصدر.

المحاكي لم يقلع من بيئة التنفيذ الحالية. مجموعات الاختبار السبع على الجهاز لكل مشروع مكتوبة ومجمّعة في حزمة اختبارات، لكنها لم تُنفذ بعد. مراجعة الواجهة بصريًا، والتحقق من التذكيرات أثناء السكون وبعد إعادة التشغيل، واختبار أحجام الشاشات، تظل معلّقة. لا يوجد ادعاء بجاهزية إنتاجية.

لتنفيذ الاختبارات من الجهاز نفسه، شغّل «اختبار التطبيقات.cmd» داخل «تطبيقات أندرويد» بعد تشغيل محاكي أو توصيل جوال واحد. يثبت نسخ Debug ويضيف سجلات تجريبية دون مسح سجلات المستخدم. تُحفظ النتائج والصور محليًا في «نتائج اختبار الجهاز». ملفات APK موقعة بمفتاح Debug محلي غير مرفق؛ قد تحتاج إزالة النسخة التجريبية قبل تثبيت بناء من مفتاح مختلف، وهذا يحذف بياناتها المحلية.
