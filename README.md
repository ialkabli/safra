# سَفرة · Safra

تطبيق أندرويد عربي أصلي لـحجز السفر. مشروع تجريبي لعبدالمجيد حسن كابلي، @iprigner، يعمل محليًا دون اتصال.

## ما يقدمه

سعة المقاعد لكل رحلة ويوم، وحفظ إجمالي السعر بالهللة، وإعادة المقاعد عند الإلغاء.

SQLite transaction للحجز الذري؛ مفتاح محاولة يمنع تكرار الحجز؛ السعر محفوظ وقت الحجز.

## التشغيل والبناء

افتح مجلد المشروع في Android Studio وحدد SDK من إعدادات البرنامج. يتطلب Android 8.0 / API 26 أو أحدث. إعداد المشروع يستخدم Java 17 وAndroid SDK 37.0، وAGP 9.5.0 وGradle 9.6.0. استخدم JDK المضمّن مع Android Studio أو JDK متوافقًا مع إصدار Gradle.

```sh
./gradlew assembleDebug assembleDebugAndroidTest
```

ويندوز: استخدم `gradlew.bat`. ملف التثبيت الناتج `app/build/outputs/apk/debug/app-debug.apk`. ملف APK الجاهز محفوظ خارج الشيفرة ضمن مجلد ملفات التثبيت عند التسليم، وهو نسخة Debug تجريبية.

## الاختبارات

- `scripts/check-rules.cmd`: 14 تحققًا مستقلًا لقواعد التحقق والتواريخ والحسابات؛ يحتاج JAVA_HOME.
- `app/src/androidTest`: سبع مجموعات اختبار على أندرويد، تشمل قاعدة البيانات وواجهة المستخدم، عبر Instrumentation runner مستقل عن المكتبات الخارجية.
- `scripts/check-device.cmd`: يبني ويثبت التطبيق وحزمة الاختبارات ثم ينفذها على جهاز أندرويد متصل واحد. يضيف سجلًا تجريبيًا باسم «اختبار واجهة تجريبي»؛ لا يَحذف سجلات المستخدم.
- حالة التنفيذ الفعلية موثقة في `docs/VERIFICATION.json`. وجود الاختبارات لا يعني أنها نُفذت على جهاز في هذه الجلسة.

## البنية

`MainActivity`: شاشات أصلية باستخدام Android Views. `Ui`: مكونات العرض وعمليات الخلفية. `Store`: قواعد الحجز أو المهام والتخزين. `Rules`: تحقق مستقل عن أندرويد. `Art`: رسومات Canvas أصلية قابلة لتغيير الدقة. قاعدة SQLite خاصة بالتطبيق، والكتابة خارج خيط الواجهة. الاستعلامات ممررة بالمعاملات لحماية إدخال المستخدم.
